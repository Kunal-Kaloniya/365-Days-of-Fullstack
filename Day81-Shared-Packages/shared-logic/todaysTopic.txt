=== Internal Package Management ===
When you have multiple apps (e.g., a "Customer App," an "Admin Dashboard," and a "Mobile API"),
you need a Single Source of Truth.

=== Semantic Versioning (SemVer) ===
1. Verdaccio: A popular lightweight private NPM proxy/registry you can host yourself.

2. The "Shared" Strategy: You create a folder named @my-company/ui-core. It contains your React components, Tailwind config, and TypeScript types.

3. Version Control: * 1.0.1 (Patch): Bug fixes.
    a) 1.1.0 (Minor): New features, no breaking changes.
    b) 2.0.0 (Major): Breaking changes (e.g., changing a prop name).

4. CI/CD Integration: Automatically publishing a new version to your private registry whenever code is merged into the main branch of your UI repo.


=== MICROLAB ===
Initialize a "Shared Constants" package that can be used by both your Frontend and Backend to keep error codes and validation limits synced.
